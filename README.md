# Lilitu Rodac — site content

The editable words, lists and pictures for https://liliturodac.com.

Edit them in the content editor at https://liliturodac.com/admin/ (sign in with GitHub). Each **Publish** there
is a commit to this repository, and the website reads this repository live, so changes show on the site within
about a minute. No rebuild is needed.

- `content/*.json` — one file per page, plus the nuggets, the Firefly quotes and the Writing library settings.
- `media/` — pictures uploaded in the editor (shown on the site at `/content-media/…`).

The essays themselves are not here; they come from Substack. Don't put paid essay text, private contact details
or anything unpublished in this repository: it is public.
